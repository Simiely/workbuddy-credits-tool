# 技术栈 · 精确版本与模块

## 运行时

| 组件 | 版本/要求 | 说明 |
|---|---|---|
| Node.js | ≥ 18(开发 22.x) | 原生 `fetch` / `AbortController` / `node:sqlite` 必需 |
| 浏览器 | Edge(Chromium) | 仅添加账号时需要(读 cookie) |
| 第三方依赖 | **零** | 全部用 `node:` 内置模块 |

## 进程结构

```
wb-credits.mjs   CLI 入口(命令分发,只读查询不落盘)
wb-gui.mjs       GUI 服务(本地 HTTP,默认 8080,被占顺延至 ≤8090;路由登记制 + 文件地图注释)
edge-daemon.mjs  浏览器代理(独立进程,持 CDP WebSocket,HTTP API 8129 / Edge 调试 9222,CDP 标准发现 /json/version;断线自动重连)
```

## 后端模块(src/,CLI 与 GUI 复用)

| 模块 | 职责 | 关键导出 |
|---|---|---|
| `config.js` | 集中常量 + 环境变量 | `WB_COLLECTOR`(edge/file)/ 端口 / 并发 / 超时 |
| `store/db.js` | SQLite 单例(真相源) | `getDb`(readings 时序表 + 迁移 + WAL) |
| `collect/*` | 采集方案工厂 | edge(Edge CDP)/ file(文件+WebDAV) |
| `compute/client.js` | 内部接口 HTTP 客户端 | `fetchCredits / probeAccount` |
| `compute/model.js` | 唯一解析口径 | `buildSnapshotEntry` 等 |
| `compute/query.js` | 查询编排(并发 6/容错) | `fetchAllAccounts / fetchOneAccount` |
| `compute/store.js` | 账号池读写 | `loadAccounts / saveAccounts / addOrUpdateAccount` |
| `compute/history.js` | 时序 + 缓存(合并导入) | `appendSnapshot / historyFor / importLegacy` |
| `compute/derive.js` | 派生纯函数(单派生源) | `deriveAccount / deriveGiftExpiry` |
| `compute/sample.js` | **唯一采样入口** | `sampleAll({onSampled})` |
| `compute/scheduler.js` | 自适应调度 + SSE | `startScheduler / runOnce` |
| `compute/webdav.js` | WebDAV 云同步 | `uploadFile / downloadFile / testConnection` |
| `compute/account-ops.js` | 添加账号 | `saveCurrentFromEdge` |
| `present/render.js` | CLI 渲染 | markdown / CSV |

## 前端文件(7 个 classic script,加载顺序即依赖方向)

```
state → core → render → chart → ops → sync → actions
```

| 文件 | 职责 |
|---|---|
| `wb-gui.state.js` | 共享状态/常量/helper(`S`/`dashPer`/`LINE_COLORS`/`escAttr`) |
| `wb-gui.core.js` | `api()`/弹窗/管理员三态(设置/清除/会话验证) |
| `wb-gui.render.js` | hero/卡片/账号总览表格/到期柱图 |
| `wb-gui.chart.js` | 趋势柱状图/每日窗口(3~7 天数据对齐)/图例(含合计)/模式切换 |
| `wb-gui.ops.js` | 账号操作:排序(过期/使用/剩余)/改名/删除/添加/导出/清空 |
| `wb-gui.sync.js` | WebDAV 云同步 |
| `wb-gui.actions.js` | 刷新编排/自动刷新/SSE/启动接线(唯一副作用启动段) |

## 数据文件(运行时生成,均已 gitignore)

| 文件 | 内容 | 敏感性 |
|---|---|---|
| `wb-accounts.json` | 账号池(每账号 cookie 凭证) | 🔴 严禁外传 |
