# WorkBuddy 多账号积分工具

多账号采集 **WorkBuddy 积分**,提供命令行(CLI)与本地网页仪表盘(GUI)两种入口。
直接调用 WorkBuddy 网页版内部接口,无需开浏览器(仅"添加账号"时需要 Edge)。

## 功能特性

- **多账号池**:每个账号独立 cookie 凭证,一键批量查询,单账号失败不影响其他
- **CLI**:`accounts` / `save-current` / `rename` / `del` / `all` / 单账号查询,支持 `--json` / `--csv`
- **GUI 仪表盘**:深色粉红主题、移动端适配;总剩余大数字状态层 → 消耗趋势(折线,按天/月聚合、账号图例开关、**当日有消耗自动标点**)→ 账号卡片明细
- **到期预警**:账号总览表与明细弹窗展示**近1天/近3天过期积分**(基于 `CycleEndTime` 计算),明细弹窗柱子新增 1天/3天到期
- **一键排序**:操作条「剩余排序」「近1天过期排序」按指标从多到少重排卡片并持久化
- **消耗历史**:每次刷新记录快照(同分钟去重,保留 500 条),折线/表格展示"剩余积分变化"
- **本地缓存**:最近一次完整数据落盘,断网/接口失败也能看
- **WebDAV 云同步**:账号池 + 历史 + 缓存一键备份到坚果云/Nextcloud 等,换电脑下载即恢复
- **导出 MD 报表**:按账号分节,可直接阅读/转 PDF
- **自动刷新**:间隔可调(1~1440 分钟),设置本地记忆

## 快速开始

> 依赖:Node.js ≥ 18(开发环境 22.x),仅添加账号时需要 Edge 浏览器。

### 方式一:GUI 仪表盘(推荐)

```bash
node wb-gui.mjs        # 或 Windows 双击 wb-gui.bat
# 自动打开 http://127.0.0.1:8080(端口被占自动顺延)
```

### 方式二:命令行

```bash
node wb-credits.mjs accounts                     # 查看账号池
node wb-credits.mjs all                          # 一键批量查询全部账号
node wb-credits.mjs --account 1 --json           # 查询单个账号(原始 JSON)
```

### 首次使用:添加账号(每个账号约 10 秒)

1. 启动 `edge-daemon.mjs`(浏览器代理,添加账号必需);
2. 打开 Edge 登录 workbuddy.cn 的**账号 A**;
3. GUI 点「＋ 添加当前账号」,或命令行 `node wb-credits.mjs save-current`;
4. Edge 退出登录,换**账号 B** 重复 2~3 步;
5. 全部添加完,点「刷新全部」/ `node wb-credits.mjs all`。

## CLI 命令速查

| 命令 | 作用 |
|---|---|
| `save-current [备注名]` | 把当前 Edge 登录的账号加入/更新账号池 |
| `accounts` | 列出账号池(显示名/手机号/Uin/状态/凭证到期) |
| `rename <序号\|id\|Uin> <显示名>` | 设置显示名称(仅展示,不改底层数据) |
| `del <序号\|id\|Uin>` | 删除账号 |
| `all [--csv 路径]` | 批量查询全部账号(汇总表 / CSV) |
| `[--account <序号\|id\|Uin>] [--json\|--csv 路径]` | 单账号查询 |

## 数据与隐私

- `wb-accounts.json` 含**所有账号登录凭证**,仅存本机,**严禁外传/上传**;仓库已 gitignore
- 凭证约 7 天过期,过期账号标记"⚠️ 凭证过期",重新登录后 `save-current` 更新
- 备份/迁移用 GUI「☁️ 云同步」(上传/下载,存到你的 WebDAV)或「🧹 清空本地数据」前的导出
- 查询不依赖浏览器,仅需网络直连 `www.workbuddy.cn`
