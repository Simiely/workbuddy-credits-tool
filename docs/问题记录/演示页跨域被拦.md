# 问题:演示预览页请求 GUI 服务被跨域拦截

**TL;DR**:自包含演示 HTML 由静态预览服务(如 127.0.0.1:54359)打开时,请求 8080 属跨域,服务端无 CORS → 浏览器拦截,请求永远 pending(表现为刷新一直转)。

- 问题:在演示预览页点刷新无响应,按钮一直转;而直连 8080 正常
- 根因:浏览器同源策略拦截跨域请求,服务端未返回 CORS 头
- 解决:GUI 服务全部响应加 `Access-Control-Allow-Origin: *` + `Access-Control-Allow-Methods/Headers`,`OPTIONS` 预检直接放行
- 预防:本地工具被"其他端口页面"调用时必须开 CORS;排查"请求挂起"先分清是同源直连还是跨域
