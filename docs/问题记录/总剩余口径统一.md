# 问题:总剩余口径不含体验版基础用量

**TL;DR**:折线图/表格/卡片只算"赠送积分剩余",与明细弹窗"剩余总积分 = 体验版 + 赠送"对不上。

- 问题:仪表盘总剩余数字与明细卡不一致,用户困惑"到底剩多少"
- 根因:各处独立计算,部分位置(折线、条形、卡片)漏掉体验版基础用量,只用了赠送剩余
- 解决:统一口径——**所有"总量/剩余" = 体验版基础用量 + 赠送积分**,累计已用同理;后端 `historyFor`(补 `totalRemain/totalUsed`)与 `/api/dashboard/all` 统一计算,老快照缺 `baseUsed` 按 0 兼容;前端卡片/折线/表格/消耗历史全部改走统一口径
- 预防:新增任何"总量/剩余/已用"展示前,先确认口径是否包含体验版;前端不要自行用旧口径计算
