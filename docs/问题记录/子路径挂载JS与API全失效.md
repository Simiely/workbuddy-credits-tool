# 子路径挂载 JS 与 API 全失效(页面能开、按钮全无效)

> **TL;DR**:页面挂载到 `/tool/<id>/` 子路径后,HTML 里绝对路径资源(`/app.js`)和 JS 里绝对路径 API(`/api/..`)都会解析到平台根 → 404 → 按钮全部失效。修复:资源用相对路径,API 用 `__BASE__` 前缀(独立运行 `__BASE__=""` 不变)。

## 问题

- 现象:工具被工具中心(或任何子路径平台)挂载后,页面能打开(HTML 反代正常),但**所有按钮无效**。
- 原因:① `<script src="/app.js">` 在 `/tool/<id>/` 下解析为 `平台根/app.js`(404,JS 根本没加载);② JS 里 `fetch("/api/..")` 同样打到平台根(404/路由错)。

## 根因

工具按"独立站点"编写时自然用绝对路径;子路径挂载要求**所有资源/接口引用相对化**。

## 解决

两层配合:

1. **工具层(v1.0.2)**:
   - HTML:`script src` 改相对路径 `./app.js`
   - JS 顶部:`const __BASE__ = window.__BASE__ || (location.pathname.match(/^\/tool\/[^/]+/) || [""])[0];`
   - 所有 `/api/*` 调用改 `__BASE__ + "/api/*"`
2. **平台层(tools-center v0.4.6)**:app 型 HTML 响应自动注入 `window.__BASE__="/tool/<id>"`(仅 text/html);v0.4.7 再加 `/tool/<id>` 无尾斜杠 301 到带斜杠,保证相对路径始终正确。

## 预防

- 写页面工具默认用相对路径 + `__BASE__` 前缀(见使用指南「子路径挂载约定」)
- 纯后端工具(只返回 JSON)无需关心
