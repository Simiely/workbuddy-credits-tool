# 架构说明

> WorkBuddy 积分工具 · 完整架构。CLI 与 GUI 双入口,共享 `lib/` 模块层;浏览器仅在"添加账号"时需要。

## 一、目录结构

```
tools/
├── wb-credits.mjs      # CLI 入口:命令分发 + 薄调用(127 行)
├── wb-credits.bat      # CLI 快捷启动(Windows)
├── wb-gui.mjs          # GUI 服务:本地 HTTP + API 路由(229 行)
├── wb-gui.html / .js   # 前端:页面结构样式 / 逻辑(服务每次请求实时读取)
├── wb-gui.bat          # GUI 快捷启动
├── edge-daemon.mjs     # 浏览器代理(独立进程,CDP WebSocket,HTTP API 8129 / Edge 调试 9222)
├── edge-ctl.mjs        # 通用浏览器调试工具(日常不用)
├── lib/                # ★ 共享模块层(CLI 与 GUI 复用,11 个模块)
├── rules/              # AGENTS.md 按需 @引用的规则细节
├── docs/               # 架构文档 + 问题记录(一坑一篇)
├── legacy/             # 历史一次性脚本/旧前端(留档)
└── (运行数据见 rules/技术栈.md,均已 gitignore)
```

## 二、模块职责(依赖方向自上而下)

```
wb-credits.mjs ──┐
                 ├──► lib/query.js ──► lib/accounts.js / lib/workbuddy.js / lib/summarize.js
wb-gui.mjs   ────┤
                 ├──► lib/account-ops.js ──► lib/cookies.js / lib/workbuddy.js / lib/accounts.js
                 ├──► lib/render.js ──► lib/accounts.js
                 ├──► lib/history.js / lib/webdav.js ──► lib/util.js(全局常量)
                 └──► lib/daemon.js ──► edge-daemon.mjs ──► Edge(CDP)
```

| 模块 | 职责 | 关键导出 |
|---|---|---|
| `lib/util.js` | 全局常量:路径/端口/并发/超时/上限 | `TOOLS_DIR / CONCURRENCY / FETCH_TIMEOUT_MS / DAEMON_PORT / GUI_PORT / HISTORY_LIMIT` |
| `lib/accounts.js` | 账号池唯一读写入口;迁移旧文件;去重更新;查找 | `loadAccounts / saveAccounts / findAccount / addOrUpdateAccount / mergeAccounts / displayName` |
| `lib/workbuddy.js` | 内部接口客户端;401→`CredentialExpiredError`;探测 Uin;请求超时 | `fetchCredits / probeAccount / CredentialExpiredError` |
| `lib/cookies.js` | 经代理读 Edge cookie;计算过期时间;读手机号(workbuddy 页面) | `getEdgeCookies / phoneFromPage` |
| `lib/daemon.js` | edge-daemon 的 HTTP 客户端 | `daemonTabs / daemonCmd / daemonEval` |
| `lib/query.js` | 查询编排:批量(并发/容错/状态持久化)+ 单账号 | `fetchAllAccounts / fetchOneAccount` |
| `lib/account-ops.js` | 添加账号:读 cookie→校验→入池去重更新 | `saveCurrentFromEdge` |
| `lib/summarize.js` | 汇总口径(体验版/有效赠送包/已过期) | `summarize` |
| `lib/render.js` | 渲染:单/多账号 markdown、MD 报表(按账号分节)、CSV、账号摘要 | `renderSingleMarkdown / renderAllMarkdown / mdAll / csvAll / csvSingle / brief / SHORT_PKG` |
| `lib/history.js` | 本地缓存 + 历史快照(同分钟去重,500 上限) | `saveLastData / loadLastData / appendSnapshot / historyFor / loadHistory` |
| `lib/webdav.js` | WebDAV 云同步:Basic Auth、多级目录逐级 MKCOL、上传/下载 | `uploadFile / downloadFile / testConnection / loadSyncConfig / saveSyncConfig / BACKUP_DIR / SYNC_FILES` |

## 三、数据流

### 添加账号(唯一需要浏览器的一步)
```
Edge 登录 workbuddy.cn → save-current / GUI「＋添加当前账号」
  → lib/account-ops.saveCurrentFromEdge
      ├─ lib/cookies.getEdgeCookies(经 edge-daemon 读 cookie)
      ├─ lib/workbuddy.probeAccount(校验 + 探测 Uin)
      └─ lib/accounts.addOrUpdateAccount(按 Uin 去重,保留 displayName)
  → 写 wb-accounts.json
```

### 查询积分(无需浏览器)
```
CLI all / GUI「刷新全部」→ /api/all
  → lib/query.fetchAllAccounts(并发 6,单账号 8s 超时,失败标记 lastStatus)
  → 汇总/渲染(CLI 表格 / GUI 仪表盘)
  → 写 wb-last-data.json(缓存)+ appendSnapshot(wb-history.json 快照)
```

### 消耗仪表盘
```
/api/dashboard/all
  → lib/history.loadHistory(快照)
  → 总剩余趋势(每快照:Σ(赠送剩余+体验版剩余),时间升序)
  → 每账号折线序列(series,升序)+ 当前剩余/累计已用/记录期消耗
  → 前端:表格版 + 折线版(图例开关、按天/月聚合)
```

## 四、账号池字段(wb-accounts.json)

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识(`acc` + 时间戳 base36) |
| `name` | 原始名称(手机号或"账号N") |
| `displayName` | 显示名称(用户自定义,空则用 name) |
| `uin` | 腾讯云账号标识(去重键) |
| `cookieHeader` | 登录凭证(Cookie 请求头,🔴 敏感) |
| `sessionExpiresAt` | 认证 cookie 过期时间 |
| `lastStatus` | `ok` / `expired` / `error` |
| `addedAt` / `updatedAt` | 时间戳 |

| 来源 | 接口 | 说明 |
|---|---|---|
| WorkBuddy 网页 | `POST https://www.workbuddy.cn/billing/meter/get-user-resource` | 积分资源(内部接口,无公开文档) |

## 六、维护指南

### 新增/修改功能
1. **业务逻辑** → 改 `lib/` 对应模块(CLI/GUI 自动同步);**展示** → CLI 在 `wb-credits.mjs` 底部,GUI 在 `wb-gui.html/js`
2. 新增账号字段 → `lib/accounts.js` 的 `addOrUpdateAccount` 注意保留用户自定义字段;前端 `brief` 需同步
3. 改前端免重启;改后端需重启 GUI 服务

### 改版后必须验证
```bash
node --check wb-credits.mjs && node --check wb-gui.mjs && node --check wb-gui.js
node wb-credits.mjs accounts && node wb-credits.mjs all
curl http://127.0.0.1:8080/api/all          # 重启 wb-gui.mjs 后
```

### 常见问题
| 现象 | 处理 |
|---|---|
| 查询报"凭证失效" | cookie 过期(约 7 天),重新登录后 `save-current` 更新 |
| save-current 报"代理未运行" | 启动 `edge-daemon.mjs`;GUI 首页有醒目提示 |
| GUI 打不开 | 检查 8080 被占(自动顺延,看 `wb-gui.log`) |
| 接口 401 但账号标记正常 | WorkBuddy 内部接口改版,查 `lib/workbuddy.js` |
| 刷新一直转圈 | 前端 12s 超时兜底,必恢复;仍异常查 Console |

## 七、风险与限制

- **内部接口无公开文档**:官方改版需同步 `lib/workbuddy.js`;兜底 = legacy 的 CDP 采集思路
- **凭证敏感**:`wb-accounts.json` / `wb-sync.json` 严禁外传/上传(仓库已 gitignore)
- **采集频率**:批量并发 6,属低频访问;勿大幅提高并发
- **云同步为明文传输**:建议 WebDAV 地址使用 https;如需内容加密可后续加 AES
