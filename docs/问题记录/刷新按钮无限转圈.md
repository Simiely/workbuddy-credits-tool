# 问题:刷新按钮无限转圈

**TL;DR**:请求没有超时保护,WorkBuddy 接口挂起时 `/api/all` 一直 pending,前端按钮永远转。

- 问题:点击「刷新全部」后按钮一直转,看起来卡死
- 根因:① 服务端 `fetchCredits` 无超时,接口慢/挂起时请求不返回;② 前端无兜底,按钮状态在 `finally` 前不恢复
- 解决:双层超时——服务端单账号 8s(`AbortController`,超时报"接口响应超时",单账号失败不拖累其他);前端整体 12s(超时报"刷新超时,请重试"),`finally` 保证按钮必恢复
- 预防:所有请求必须带超时;按钮状态单点控制(`setBusy`/loading 标志),任何路径都走 `finally` 恢复
