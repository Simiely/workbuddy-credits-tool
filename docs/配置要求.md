# 配置要求清单（接口 / 运行需要哪些配置）

> 本文列出工具运行时**需要的全部配置**:哪些必填、哪些可选、默认值、打包时是否自动预填。
> **核心目标:平台版 zip 打包时自动预填配置 → 上传 tools-center 后零输入、开箱即用。**

## 一、数据流概览(工具对接的"接口")

```
WorkBuddy 接口(www.workbuddy.cn/billing/...):查询积分 —— 无需配置
      ↑ cookie 凭证(credits.db 账号表,桌面端采集,WebDAV 同步过来)
WebDAV 接口(url/user/pass):账号池 + 历史备份/恢复 —— 平台版必需
      ↑ 桌面端「云同步上传」/ 平台版「云同步下载」
```

> WorkBuddy 接口本身**零配置**:cookie 由桌面端采集,经 WebDAV 同步到平台版。

## 三、打包预填机制

```bash
# 项目根执行:自动完成 ① 读本机 wb-sync.json ② 复制代码 ③ 写入 wb-sync.json ④ 生成 zip(桌面)
node pack-platform.mjs [输出目录]
```

- 预填的 `wb-sync.json` 内容与桌面版一致(同一套 WebDAV),平台版「☁️ 下载」无需再输入账号
- **安全边界**:`wb-sync.json` 在 gitignore(严禁进仓库);仅进入**个人部署 zip**(存桌面,不上传公网)
- 🔴 **公开发布(zip 上传 GitHub Release 等公网)必须空壳**:打包前暂移本机 `wb-sync.json`(或置空 `{"url":"","user":"","pass":""}`)再打包,发公开后部署者自行在 GUI 填写;2026-08-11 事故——旧资产把明文 WebDAV 密码打进公开 zip,已替换干净包(铁律见 `docs/发布规范.md`)
- 若不想预填(比如换 WebDAV),删除 zip 内 `wb-sync.json` 或打包前暂移本机该文件,部署后手动在 GUI 填写

## 四、部署后验收

1. 上传 zip → 平台卡片出现并自动启动(健康检查通过)
2. 打开 `/tool/wb-credits/` → 「☁️ 云同步 → 下载」→ 账号池 + 历史恢复(若 WebDAV 已有备份)
3. 无需输入任何配置即完成接入
