# 问题:历史快照乱序导致折线方向颠倒

**TL;DR**:快照数组顺序不保证时间升序(注入/写入顺序打乱),折线按数组顺序画会来回跳、趋势失真。

- 问题:折线图方向混乱,消耗趋势看不出下降
- 根因:`historyFor` / dashboard 聚合直接按快照数组顺序用,未排序;测试注入或历史较长时顺序不可靠
- 解决:所有历史读取处按 `ts` **时间升序排序**(`historyFor` 与 `/api/dashboard/all` 的 totals/series 均 `.sort((a,b)=>a.ts<b.ts?-1:1)`)
- 预防:历史数据读取即排序,约定"时间升序"为历史 API 的输出契约
