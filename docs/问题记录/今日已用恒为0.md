# 今日已用恒为 0(聚合指标被"中途加账号"污染)

> **TL;DR**:今日已用 = "今日最早全账号聚合总剩余 − 最新聚合总剩余",但当天新加账号让总量跳增 → 差值负数 → 恒显示 0。修复:按每账号分别算消耗再求和。

## 问题

- 现象:今日已用显示 0,但实际今天有明显消耗(总剩余在降)。
- 代码:前端 `updateTodayUsed()` 用 `/api/dashboard/all` 的 `totals`(全账号聚合)做"今日最早 − 最新"。

## 根因

`totals` 是所有账号剩余之和。**当天中途加入 5 个新账号**,总量从 4227 跳到 28898:

```
今日最早 total = 4227(1 个账号时)
今日最新 total = 28534(6 个账号,有消耗)
差值 = 4227 − 28534 = 负数 → 代码 diff>0 才显示 → 0 ❌
```

新账号的加入是"总量上涨",掩盖了真实消耗。

## 解决(v1.0.7)

改为按**每账号 series** 分别算:

```js
for (const a of per) {
  const today = a.series.filter(p => isToday(p.t));
  if (today.length < 2) continue;
  const diff = today[0].v - today[today.length - 1].v;  // 该账号今日最早−最新
  if (diff > 0) totalUsed += diff;                       // >0 才计入(消耗)
}
```

新账号没有"今早快照",只贡献它加入后的消耗,不再污染总量。实测今日已用 = 486(正确)。

## 预防

- **聚合类指标(总量/差值)在集合成员会变化时不可直接相减**——先按最小稳定单元(账号)计算,再汇总
- 同理适用于"今日会过期"等跨账号统计,均按账号粒度聚合
