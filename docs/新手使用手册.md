# WorkBuddy 积分监控工具 · 新手使用手册

> 适用:Windows 电脑(桌面版)。本手册从零开始,没接触过的人也能照着跑起来。
> 当前运行状态:本机实例地址 `http://127.0.0.1:8080`,已配置 6 个账号。
> **推荐方式:单文件 exe(免安装 Node.js,双击即用,见第 2 节);第 8 节是源码/Node.js 方式。**

---

## 1. 这是什么工具?

一个**多账号积分监控仪表盘**。如果你有好几个 WorkBuddy 账号,想一眼看清:

- 每个账号还剩多少积分(体验版 + 赠送包)
- 今天用了多少、和昨天比是多了还是少了
- 近几天的消耗趋势(柱状图)
- 哪些积分包快过期了

它就帮你把这些数据集中到**一个网页仪表盘**里,自动刷新,还能导出报表。

> 它直接调用 WorkBuddy 网页版的内部接口,不需要打开浏览器就能查积分(只有「添加账号」时需要 Edge 浏览器)。

---

## 2. 快速开始(单文件 exe,推荐)

**前提:一台 Windows 电脑,无需安装任何东西(Node.js 都不用)。**

1. 拿到 `WorkBuddy-Credits-Monitor.exe`(放在一个文件夹里,建议整个文件夹一起保管)
2. **双击 exe** → 自动启动服务并打开浏览器 `http://127.0.0.1:8080`
3. 看到仪表盘即可使用

**数据在哪**:所有数据(积分历史、账号凭证)保存在 **exe 所在文件夹**里。想备份/迁移,把整个文件夹复制走即可。

**关闭程序**:关掉弹出的黑色命令行窗口。

> exe 版已内置浏览器代理:一个程序同时提供仪表盘(8080)和账号采集(8129),「添加当前账号」开箱即用。

---

## 3. 安装与启动(源码 / Node.js 方式)

### 第一步:装 Node.js

- 去 https://nodejs.org 下载并安装 **Node.js 22.x**(LTS 版本即可),一路「下一步」。
- 装完验证:打开命令行(按 `Win+R`,输入 `cmd`,回车),输入:

```bash
node --version
```

能显示版本号(如 v22.x)就说明装好了。

### 第二步:启动仪表盘

**方式 A(推荐,最简单):双击 `wb-gui.bat`**

**方式 B(命令行):**

```bash
cd 项目文件夹路径
node wb-gui.mjs
```

看到提示 `WorkBuddy 积分仪表盘已启动: http://127.0.0.1:8080` 就成功了。

### 第三步:打开界面

用浏览器(推荐 Edge)打开 **http://127.0.0.1:8080**

> 如果 8080 端口被别的程序占了,它会自动顺延到 8081,以启动时提示的地址为准。

---

## 4. 界面怎么看

打开后从上到下:

| 区域 | 显示内容 |
|---|---|
| 顶部大数字 | **所有账号总剩余积分**(体验版基础用量 + 赠送积分合计) |
| 中部柱状图 | **每日消耗趋势**(每天各账号消耗多少,右侧灰色柱是当日合计) |
| 底部卡片区 | **每个账号一张卡**:显示名、剩余积分、今日已用、是否已签到、积分包到期明细 |

### 常用操作

- **刷新全部**:点顶部「刷新全部」按钮,立即重新查询所有账号(约 10~30 秒)
- **自动刷新**:点「⚙ 设置」可调自动刷新间隔(1~1440 分钟),关掉界面也照常后台采集
- **排序**:账号总览表可按「过期排序 / 使用排序 / 剩余排序」一键重排(选择会记住)
- **折叠面板**:点趋势/总览面板的标题可折叠/展开,省空间
- **导出报表**:可导出 Markdown 报表(可直接阅读/转 PDF)

## 5. 第一次使用:添加账号(核心步骤)

> 「添加账号」的意思是:把你登录过的 WorkBuddy 账号的**登录凭证(cookie)**采集下来,存到本机,以后查积分就不用再登录。
> 每个账号约 10 秒。**只在第一次需要**,以后启动直接用。

### 前置:让浏览器能被工具"读取"

1. 用**带调试参数**的方式启动 Edge(见下方「小技巧」)
2. 保持 Edge 打开着

### 添加流程

```
① 启动浏览器代理:命令行运行  node edge-daemon.mjs 8129
   看到 [daemon] CONNECTED 说明已连上 Edge
② 在 Edge 里打开 https://www.workbuddy.cn ,登录【账号 A】
③ 回到仪表盘页面(127.0.0.1:8080),点「＋ 添加当前账号」
   弹窗里可以填个备注名(如"坤坤"),点确定,约 10 秒完成
④ 在 Edge 里退出登录,换【账号 B】登录,重复 ③
⑤ 全部账号添加完,点「刷新全部」→ 每个账号一张卡片,搞定
```

> **小技巧:用调试模式启动 Edge(必须)**
> edge-daemon 靠这个参数才能读到浏览器里的登录状态。创建一个 Edge 快捷方式,在「目标」末尾加:
>
> ```
> --remote-debugging-port=9222
> ```
>
> 以后都用这个快捷方式开 Edge 即可。

### 命令行添加账号(可选)

```bash
node wb-credits.mjs save-current 坤坤   # 添加当前 Edge 登录的账号
node wb-credits.mjs accounts            # 查看账号池列表
node wb-credits.mjs all                 # 命令行批量查询全部账号
```

## 6. Cookie 过期了怎么办(重要)

### 怎么知道过期了

- 账号卡片状态显示 **❌ 错误** / **凭证失效**
- 命令行 `accounts` 列表里状态列不是 ✅

### 怎么更新

```
① Edge 打开 https://www.workbuddy.cn ,重新登录该账号
② 仪表盘点「＋ 添加当前账号」(会自动覆盖旧凭证)
③ 点「刷新全部」→ 恢复 ✅
```

**不用删账号重加**,「添加当前账号」会自动按手机号去重更新。

> 小知识:登录凭证一般有效期约 1 个月(当前这批到 2026/8/10),到期前重新登录一次即可。

## 7. 数据与隐私(务必读)

- 所有账号凭证只存在**本机**项目的 `credits.db`(SQLite 数据库)里,**不要把这个文件发给任何人**
- 查询积分不需要浏览器,只联网访问 `www.workbuddy.cn`
- 数据真相源是 `credits.db`;`wb-accounts.json` 只是 WebDAV 迁移用的镜像
- 断网/接口失败时,仪表盘会显示**上次缓存的数据**,不影响查看

## 8. 与服务器/平台版同步(可选,进阶)

如果你还有 Docker/NAS/平台托管版,想让它们共用同一份账号数据和积分历史:

```
① 本机仪表盘点「☁️ 云同步 → 配置」,填你的 WebDAV 地址(如坚果云/Nextcloud)
② 点「上传」→ 账号池 + 历史一键备份到云端
③ 在平台版上「☁️ 云同步 → 下载」→ 数据合并导入,不破坏平台版已有历史
```

> 平台版自己不采集 cookie(容器里没有浏览器),**它只能通过「云同步下载」拿到你在本机更新的凭证**。所以 cookie 更新一定要在本机做。

## 9. 常见问题(FAQ)

**Q1:全部账号查询失败,报"接口响应非 JSON(HTTP 400)"**
A:多半是 cookie 太大被网关拒绝(历史遗留)。先用 CLI 跑一次 `node wb-credits.mjs all` 看是否恢复;若仍失败,重新登录账号走「添加当前账号」更新凭证。

**Q2:启动提示端口被占用**
A:正常现象,自动顺延到下一个端口(8080→8081)。想固定 8080,把占用端口的旧进程关掉再启动。

**Q3:「添加当前账号」提示连不上浏览器**
A:Edge 没用调试参数启动。用 `--remote-debugging-port=9222` 的方式重新开 Edge,并确认 `node edge-daemon.mjs 8129` 在跑、显示 CONNECTED。

**Q4:忘记管理密码**
A:删除项目根目录的 `wb-admin.json` 文件并重启服务,即恢复"无密码开放"模式。

**Q5:改界面后没变化/浏览器显示旧版**
A:刷新页面(前端文件按请求实时读取,改完刷新即可,不用重启);若仍旧,强刷 Ctrl+Shift+R。

**Q6:电脑重启后怎么再打开**
A:双击 `wb-gui.bat`(GUI);要添加账号再开 `edge-daemon`。双击脚本会自动定位项目目录,项目放哪都行。
