# 问题:每月视图清空截止日期误切回每日视图

**TL;DR**:`onTrendEnd` 把"非每日模式"一律切成每日,用户在每月视图清空日期框想恢复"每月全量"时被意外弹回每日。

- 问题:每月视图下清空「截止日期」输入框 → 视图被切回「每日」(操作跳转,不符合预期)
- 根因:`onTrendEnd(v)` 原逻辑 `if (dashMode !== "day") changeMode("day")` 对「选值」和「清空」一刀切——清空本应"恢复当前模式的默认窗口"(每日=动态/每月=全量),却被强制切模式
- 解决:`onTrendEnd` 分流——仅 `v` 有值(选值)时自动切每日(日期框=每日视图专用语义);清空保持当前模式,只重渲染(`renderLines` 走当前模式的窗口逻辑)
- 预防:模式切换与"更新数据"要区分触发源——同一入口处理多个动作时,按动作语义分流(`if (v) 切模式 else 恢复默认`),不要对整类调用一刀切
- 相关:v1.4.57,回归测试 `test/render-lines.test.mjs` T17(每月视图清空 → 保持每月模式 + 全量)
