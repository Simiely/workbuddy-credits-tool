# 技术栈 · 精确版本与模块

## 运行时

| 组件 | 版本/要求 | 说明 |
|---|---|---|
| Node.js | ≥ 18(开发 22.x) | 原生 `fetch` / `AbortController` 必需,18 以下不可用 |
| 浏览器 | Edge(Chromium) | 仅添加账号时需要(读 cookie) |
| 第三方依赖 | **零** | 全部用 `node:` 内置模块 |

## 进程结构

```
wb-credits.mjs   CLI 入口(命令分发)
wb-gui.mjs       GUI 服务(本地 HTTP,默认 8080,被占顺延至 ≤8090)
edge-daemon.mjs  浏览器代理(独立进程,持 CDP WebSocket,HTTP API 8129 / Edge 调试 9222,CDP 标准发现 /json/version;断线自动重连)
edge-ctl.mjs     通用浏览器调试工具(日常不用)
```

## 模块清单(lib/ 共享层,CLI 与 GUI 复用)

| 模块 | 职责 | 关键导出 |
|---|---|---|
| `util.js` | 全局常量:路径/端口/并发/超时 | `TOOLS_DIR / CONCURRENCY=6 / FETCH_TIMEOUT_MS=8000 / DAEMON_PORT=8129 / GUI_PORT=8080 / HISTORY_LIMIT=500` |
| `accounts.js` | 账号池唯一读写入口(迁移/去重/查找) | `loadAccounts / saveAccounts / findAccount / addOrUpdateAccount / mergeAccounts / displayName` |
| `workbuddy.js` | 内部接口客户端;401→`CredentialExpiredError` | `fetchCredits / probeAccount / CredentialExpiredError` |
| `cookies.js` | 经代理读 Edge cookie / 手机号 | `getEdgeCookies / phoneFromPage` |
| `daemon.js` | edge-daemon 的 HTTP 客户端 | `daemonTabs / daemonCmd / daemonEval` |
| `query.js` | 查询编排:批量(并发/容错)+ 单账号 | `fetchAllAccounts / fetchOneAccount` |
| `account-ops.js` | 添加账号(读 cookie→校验→入池去重) | `saveCurrentFromEdge` |
| `summarize.js` | 汇总口径(体验版/有效/过期赠送包) | `summarize` |
| `render.js` | 渲染:markdown / MD 报表 / CSV / 摘要 | `renderSingleMarkdown / renderAllMarkdown / mdAll / csvAll / csvSingle / brief` |
| `history.js` | 本地缓存 + 消耗历史快照(同分钟去重,500 上限) | `saveLastData / loadLastData / appendSnapshot / historyFor / loadHistory` |
| `webdav.js` | WebDAV 云同步(Basic Auth,多级目录逐级 MKCOL) | `uploadFile / downloadFile / testConnection / loadSyncConfig / saveSyncConfig` |
