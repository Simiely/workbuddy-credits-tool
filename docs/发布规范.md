## 三、发布步骤

```bash
# 1. 提交并推送
git add -A && git commit -m "feat: vX.Y.Z ..."
git -c http.https://github.com.proxy=http://127.0.0.1:7890 -c http.sslVerify=false push origin main

# 2. 打 tag 并推送
git tag vX.Y.Z
git -c http.https://github.com.proxy=http://127.0.0.1:7890 -c http.sslVerify=false push origin vX.Y.Z

# 3. GitHub Release(两个 zip 资产:平台版 + bat 版;均无数据文件)
#    用 Python urllib + git credential 取 token(api.github.com curl -x 会 000;资产上传用 uploads.github.com)

# 4. 打 bat 版 zip 存发布目录(仅代码,剔除 credits.db*/wb-*.json/edge-daemon.token)
cd D:\Tool\wb-credits-tool-windows-v1.4.63   # 本地 windows 版目录(含钉死 Node 路径的 bat)
python -c "import zipfile,os;[zipfile.ZipFile('wb-credits-tool-windows-v1.4.63.zip','w',zipfile.ZIP_DEFLATED).write(os.path.join(r,f),f) for r,_,fs in os.walk('.') for f in fs if not f.startswith(('credits.db','wb-accounts','wb-last-data','wb-history','wb-sync','edge-daemon.token','wb-gui.log'))]"
# 注意:zip 条目分隔符必须为正斜杠,勿用"右键压缩"(见下)

# 5. 重打平台版 zip 存桌面(自动预填 WebDAV 配置,上传零输入;公开发布包置空壳)
node pack-platform.mjs    # 读本机 wb-sync.json → 预填 → zip 到 E:\desktop
```

> 平台版 zip 打包要点:`pack-platform.mjs` 自动完成——复制代码 + **预填 `wb-sync.json`**(WebDAV 配置,与桌面版同一套)+ 生成 `平台部署说明.md` + 顶层结构 zip;**不含** credits.db 等数据。配置要求清单见 `docs/配置要求.md`。

> 🔴 **凭证安全(2026-08-11 事故)**:公开发布到 GitHub Release 的 zip **必须清空 `wb-sync.json` 密码**(url/user/pass 全空壳),预填仅限**个人部署包**(存桌面 `E:\desktop`,不发公网)。v1.4.60 旧资产曾把明文 WebDAV 密码打进公开 zip,已替换为干净包;打包后必检:
> ```bash
> python -c "import zipfile; print(zipfile.ZipFile('x.zip').read('wb-sync.json').decode())"  # pass 必须为空
> ```
> 打干净包方法:`pack-platform.mjs` 打包前临时把项目根 `wb-sync.json` 移走/置空(如 `mv wb-sync.json wb-sync.json.bak && echo '{"url":"","user":"","pass":""}' > wb-sync.json`),打包后恢复。

> **zip 条目目录分隔符必须用正斜杠 `/`**(zip 规范 APPNOTE 强制):`pack-platform.mjs` 已遵守,勿手工"右键压缩"替代;若手工打包,条目名写成 `lib/x.js` 而非 `lib\x.js`。反斜杠打包会被 Linux unzip 判为警告(exit=1),平台 v0.12.1 前会误报"解压失败"(2026-08-06 实测事故,详见 tools-center `docs/使用指南.md`「十·一」)。打包后自检:`unzip -l` 或 `python -c "import zipfile; [print(i.filename) for i in zipfile.ZipFile('x.zip').infolist()]"`,条目名出现 `\` 即不合格。

## 四、铁律(勿犯)

- 数据文件(`credits.db*`、`wb-*.json`、备份 `credits.db.bak*`)一律不进 git / 不进包
- **公开 zip 内 `wb-sync.json` 必须空壳**(url/user/pass 全空),预填仅限桌面个人包;发公开前必检(2026-08-11 事故:旧资产泄露明文 WebDAV 密码)
- 平台版"工具目录即数据目录":**删工具 = 删数据**,发布说明里必须提醒先 WebDAV 备份
- cookie 更新只在桌面版做,平台版靠「云同步下载」
- 发布前先本地调试验证,不推半成品(用户偏好)
- 🔴 **打包前必检环境硬编码(2026-08-16 事故:v1.4.62 打包后无法用,根因见 `docs/问题记录/官方UA风控致添加凭证401.md`)**,三查:
  1. **UA 实测放行**:`src/config.js` 的 `UA` 必须当前可用——拿调试 Edge cookie 循环换 `Edg/15x.0.0.0` 测 billing API,取 200 的版本更新(官方改版后旧 UA 会被 APISIX 401,全部账号假性"凭证过期")
  2. **无打包机硬编码路径**:`grep -rn "C:\\\\Users\\\\" src/ *.mjs *.js` 应无命中;`edge-daemon.mjs` 的 `USER_DATA` 必须 `os.homedir()` 动态拼(曾硬编码 `C:\Users\2504\...`,换机器即失效)
  3. **bat 启动器冒烟**:双击 `wb-gui.bat` / `wb-credits.bat` 能出窗口且不报 `Node.js not found`(依赖 `%USERPROFILE%` 回退,启动器上下文可能不展开)
