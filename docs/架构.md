## 一、目录结构

```
workbuddy-credits-tool/
├── wb-gui.mjs          # GUI 服务:HTTP + 路由表 + 分发层 + 启动(含文件地图注释:A 基础设施/B 路由表/C 分发层/D 启动)
├── wb-gui.html         # 前端页面结构 + 样式(引用 7 个 classic script,带 ?v= 版本戳)
├── wb-gui.state.js     # 前端①共享状态/常量/helper(37 行)
├── wb-gui.core.js      # 前端②api()/弹窗/管理员三态(218 行)
├── wb-gui.render.js    # 前端③渲染:hero/卡片/账号总览/到期柱图(216 行)
├── wb-gui.chart.js     # 前端④趋势柱状图/每日窗口/图例/模式切换(v1.4.22 拆出)
├── wb-gui.ops.js       # 前端⑤账号操作:排序/改名/删除/添加/导出/清空
├── wb-gui.sync.js      # 前端⑥WebDAV 云同步
├── wb-gui.actions.js   # 前端⑦刷新编排/自动刷新/SSE/启动接线(唯一副作用启动段,最后加载)
├── wb-credits.mjs      # CLI 入口:命令分发 + 薄调用(只读查询,不落盘)
├── edge-daemon.mjs     # 浏览器代理(独立进程,CDP WebSocket,HTTP API 8129 / Edge 调试 9222)
├── src/
│   ├── config.js       # 集中常量 + 环境变量(WB_COLLECTOR 采集方案、端口等)
│   ├── domain.js       # 实体词汇表 typedef
│   ├── time.js         # 中国时区(+8)工具(唯一口径):TZ_MS/cnNow/dayKeyOf/dayOfOffset/startOfToday
│   ├── collect/        # 采集方案工厂:edge(CDP)/ file(文件+WebDAV),由 WB_COLLECTOR 或平台决定
│   ├── compute/        # 业务核心(11 模块):client/model/query/store/history/derive/gc/sample/scheduler/webdav/account-ops
│   ├── store/          # SQLite 唯一真相源(db.js,单例 + 自动迁移 + WAL)
│   └── present/        # 渲染输出(CLI markdown/CSV)
├── test/               # 回归测试(npm test 一键跑):admin-flow/history-import/render-lines/server-routes/derive-consume/gc-summary/signin-detect + helpers/vm-env(7 文件 120 断言)
├── Dockerfile / docker-compose.yml / .dockerignore   # 容器部署(P5)
├── docs/               # 架构/部署/交接/审计 + 问题记录(一坑一篇)
└── legacy/             # 历史一次性脚本/旧前端(留档)
```

前端 7 个 classic script 加载顺序(即依赖方向):`state → core → render → chart → ops → sync → actions`。
无打包器,靠顶层 `const/let/function` 共享全局词法作用域;共享状态集中在 `wb-gui.state.js`。

## 二、后端分层(依赖方向自上而下)

```
src/collect/* ──► src/compute/query ──► src/compute/client(HTTP) ──► www.workbuddy.cn 内部接口
                      │
                      ▼
              sample.sampleAll ──► appendSnapshot ──► src/store/db(readings 时序表,append-only)
                      │
                      ▼
              derive(纯函数,读 readings)──► /api/dashboard/all ──► 前端展示
                      │
              gc(历史固化,读 readings → 写 day_summary,幂等 T-2 及更早)── scheduler 按天节流
                      │
              scheduler(自适应间隔 + SSE 广播)──► 调 sampleAll
              time.js(时区工具)── 各模块统一引用(单向) 
```

| 模块 | 职责 | 说明 |
|---|---|---|
| `src/collect/*` | 采集方案工厂 | `WB_COLLECTOR=edge`(Edge CDP)/ `file`(文件+WebDAV);win32 默认 edge,其余 file |
| `src/compute/client.js` | 内部接口 HTTP 客户端 | IPv4 强制、超时、凭证失效错误类型 |
| `src/compute/model.js` | 唯一解析口径 | 原始响应 → 标准化 summary |
| `src/compute/query.js` | 查询编排 | 批量并发(6)/单账号容错/lastStatus 持久化 |
| `src/compute/store.js` | 账号池读写 | loadAccounts/saveAccounts/addOrUpdateAccount(按 Uin 去重) |
| `src/compute/history.js` | 时序 + 缓存 + 固化数据访问 | appendSnapshot(支持原始时间戳、同分钟去重)/ historyFor / 合并导入 / day_summary 读写 / 固化任务数据访问(readingsForDay/oldDayKeys/deleteReadingsBefore/allSnapshotUins);v1.4.58 起**不再 import derive**(解循环依赖),固化计算在 gc.js |
| `src/compute/derive.js` | 派生纯函数(单派生源) | currentRemain/todayUsed(**consumeByPack 包级净增量,旧快照降级 consumeByPos**)/dailyUsed/series/近1·2·3·7天过期/expiryTier/**signedInToday(detectSignIn)**;双源读取(快照日期优先 + 摘要补齐旧日);前端只读派生结果,不自己算;v1.4.58 起不再写库(固化已拆出),时区口径从 src/time.js 引用 |
| `src/compute/gc.js` | 历史固化(v1.4.58 拆出) | `gcDaySummaries()` 幂等固化 T-2 及更早(day_summary 有该日即跳过);依赖 derive(consumeByPack/detectSignIn)+ history(数据访问)+ time,单向无环 |
| `src/compute/sample.js` | **唯一采样入口** | `sampleAll({onSampled})` = 采集→快照→落盘;手动刷新(/api/all)与调度器(scheduler)都走它 |
| `src/compute/scheduler.js` | 自适应调度 + SSE 广播 | 周期调 sampleAll,维护 lastCount/lastError;按天节流调 gc.js 的固化(支线,失败不阻断采样) |
| `src/compute/webdav.js` | WebDAV 云同步 | Basic Auth、多级 MKCOL、上传/下载(历史为**合并导入**,不破坏本地);v1.4.58 起含 **`syncNow()`**(一键同步业务:拉/合/墓碑/清空保护/导/传/purge,从路由收回) |
| `src/compute/account-ops.js` | 添加账号 | 读 cookie→校验→入池(与采集层解耦) |
| `src/store/db.js` | SQLite 单例 | readings 时序表 + **day_summary 摘要表**(uin+day PK,含 signedIn)+ 迁移 + WAL |
| `src/present/render.js` | CLI 渲染 | markdown/CSV/报表 |

> **时区口径(v1.4.29/30)**:所有"自然日"计算(derive 的 dayKeyOf/startOfToday/赠送包到期)与"时间显示"(wb-gui.mjs、present/render.js 的 `cnNow()`)一律**固定中国时区(+8)**,不依赖进程时区。原因:docker 容器默认 UTC,若依赖进程时区会导致日期错位(8/3→8/2)、界面时间显示错(本地 8/5 00:47 显示成 8/4 16:47)。Dockerfile/docker-compose 已加 `TZ=Asia/Shanghai` 双保险。

> **消耗口径(v1.4.43 起为包级净增量)**:`used = baseUsed + giftUsed`(仅统计 active 包)。今日/单日消耗 = `consumeByPack(arr)`:只统计**末快照仍 active(status=0)的包**的 used 增量(首快照同包 used 为基线,首快照没有则从 0 起,负数截 0;末快照无包数据时降级 `consumeByPos` 增量口径)。历史沿革:①v1.4.31 前「首条剩余−当前剩余」在官方包数据调整日失真;②v1.4.31~42 用「已用正增量累加(consumeByPos)」——包重置回退被跳过,但官方**包失效日**(包从 active 转 status≠0)会把今日已用算得比累计还大(2026-08-06 实测:张妈妈今日 342、累计仅 38,消耗集中在当天失效的包上);③v1.4.43 收口包级:失效包当天消耗不计入今日(已随包回收),存活包消耗正常计入 → **今日已用必然 ≤ 累计已用**(用户直觉),且历史日(8/5 包到期日)不再被抹成 0。`consumed` 死字段已删除。
>
> **包级口径依赖快照 giftPackages(v1.4.47 修复)**:`consumeByPack` 只读**每天首条+末条**快照的 giftPackages 计算存活包净增量。备份剥离策略(v1.4.47)改为**每天保留首末快照组完整(含 giftPackages)、中间组剥离**——恢复/同步后口径不降级,体积几乎不变(每天 100+ 组 → 仅 2 组带包)。**勿改回 v1.4.32 的"只留最新组"**(同步/下载恢复后每天首条无包 → 降级增量口径 → 今日已用虚高,2026-08-08 实测 321→1169)。
>
> **一键同步(v1.4.46,参考 edge-multi-account-cookie「先拉后传」)**:`POST /api/webdav/sync` = ① 拉取远端 wb-accounts.json + wb-history.json(404=首次只传) ② 账号 **smart 合并**(`mergeAccountsSmart`,双向取最新 + 墓碑三态判定)、历史**合并导入**(append-only) ③ 导出本地全量(账号+墓碑+历史)覆盖上传。拉取失败(非 404)即中止不上传。**清空保护(v1.4.48)**:远端有账号但合并后本地为空 → 拒绝上传(防墓碑误删清空云端)。
>
> **墓碑删除传播(v1.4.46)**:`tombstones(uin, deletedAt)` 表记录"何时删除"。删除账号(/api/del)写墓碑并随 wb-accounts.json 备份传播——远端账号 updatedAt ≤ deletedAt → 保持删除(不复活);远端新数据 > deletedAt → 复活;本地账号 updatedAt ≤ deletedAt → 删除传播到本地。**清空账号池(/api/clear-data)不写墓碑**(本地重置不传播删除,v1.4.48 修复);TTL 30 天 `purgeOldTombstones` 清理。

> **历史固化(v1.4.32)**:`day_summary` 表固化 T-2 及更早(当日 used/startRemain/endRemain/signedIn),保留昨天+今天+最新快照;展示层双源读取(快照日期优先 + 摘要补齐旧日)。固化清理的是中间采样点(每 15 分钟一条),**浓缩为每日摘要,旧日原始明细固化后不可回看**;签到检测只用最新快照,固化不影响今天标记,历史签到靠 day_summary.signedIn 回查。备份镜像 `{snapshots, summaries}` 并剥离历史组 giftPackages(仅最新组保留)→ 3.8MB→294KB,上传 7.3s→0.4s。

> **签到检测(v1.4.33)**:官方签到接口(`check-gift-claimed`/`claim-gift`)直连被 APISIX 401 拦截,改纯元数据推断——`detectSignIn()` = 最新快照存在「今日首条快照没有 + `cycleEndTime` 对日=今天+1自然月(8/5签到→9/5到期)」的新增赠送包即为已签到。对日匹配防昨天包误判、不要求满额防签到后消耗漏判、对比首条防已存在包误报。前端卡片今日消耗行显示 ✅已签到/⏰未签到 徽标(`.sign-badge`)。

> 历史遗留:告警(`alerts.js`)、凭证过期展示、耗尽预测(`dailyRate/daysToEmpty`)已于 v1.4.13/v1.4.15 **全量下线**(前端零引用确认后删除),派生层只输出前端真正消费的字段。

## 三、数据流

### 采样(唯一入口,手动/定时共用)
```
手动刷新 /api/all 或 调度器 scheduler.runOnce
  └─► sample.sampleAll({ onSampled })
        ├─ query.fetchAllAccounts(实时查询全部账号)
        ├─ buildSnapshotEntry(汇总口径 + 赠送包子账号列表)
        └─ appendSnapshot(写入 readings 时序表,同分钟去重)
```

### 派生与展示(读写分离)
```
/api/dashboard/all
  └─ derive(读 readings + day_summary,双源)──► per[]: currentRemain/used/todayUsed/dailyUsed/series/expiring1·2·3·7d/signedInToday
        └─► 前端:hero 卡(今日 vs 昨日)、账号卡片(含签到徽标)、总览表格、趋势柱状图(每组 + 当日合计柱)
```

### 历史固化(支线,调度器按天节流)
```
scheduler(_gcDay) ──► gcDaySummaries()
  ├─ 只处理有快照的账号(allSnapshotUins)
  ├─ 幂等:day_summary 已有该日即跳过
  └─ 固化 T-2 及更早 → 保留昨天+今天+最新快照 → readings 瘦身
```

### 添加账号(唯一需要浏览器的一步)
```
Edge 登录 → save-current / GUI「＋添加当前账号」
  └─► account-ops ──► cookies(经 edge-daemon 读 cookie) + client.probeAccount(校验+探测 Uin)
        └─► store.saveAccounts(按 Uin 去重)
```

## 四、账号池字段(wb-accounts.json)

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识(`acc` + 时间戳 base36) |
| `name` / `displayName` | 原始名称 / 显示名称(用户自定义) |
| `uin` | 腾讯云账号标识(去重键) |
| `cookieHeader` | 登录凭证(Cookie 请求头,🔴 敏感) |
| `lastStatus` | `ok` / `error` |
| `addedAt` / `updatedAt` | 时间戳 |

## 五、接口一览(GUI)

`/api/status /api/accounts /api/all /api/last /api/derived /api/history?account= /api/dashboard/all /api/save-current /api/rename /api/del /api/reorder /api/export.md /api/clear-data /api/scheduler/run /api/scheduler/status /api/webdav/config|test|upload|download /api/admin/status|setup|verify|clear /api/stream(SSE)`。

## 六、维护指南

### 新增/修改功能
1. **后端业务** → 改 `src/compute/` 对应模块;**前端展示** → 按职责改 7 个文件之一(渲染→render.js,趋势→chart.js,交互→actions.js,账号操作→ops.js,同步→sync.js)
2. **新增接口** → 只在 `wb-gui.mjs` 路由表加一项(写类加 `admin:true`)
3. **改前端**刷新页面即可(实时读文件 + `?v=` 版本戳强制刷新);**改后端**需重启服务
4. **前端文件清单改动**(增删 script)必须同步 4 处:`wb-gui.html` 引用、`wb-gui.mjs` 静态路由、`test/server-routes.test.mjs` 复制正则+断言、`test/helpers/vm-env.mjs` 文件列表

### 改版后必须验证
```bash
npm test                # 7 个测试文件、120 断言(管理员/历史导入/趋势/路由冒烟/消耗口径/固化/签到)
node --check wb-gui.mjs # 语法校验
```

### 常见问题
| 现象 | 处理 |
|---|---|
| 查询报"查询失败" | cookie 失效(约 7 天),重新登录后 `save-current` 更新 |
| save-current 报"代理未运行" | 启动 `edge-daemon.mjs`;GUI 首页有醒目提示 |
| GUI 打不开 | 检查 8080 被占(自动顺延,看日志) |
| 页面显示旧版 | Ctrl+Shift+R 硬刷新(版本戳已 bump) |
| 测试红 | 前端文件清单 4 处同步点是否漏(见上) |

## 七、风险与限制

- **内部接口无公开文档**:官方改版需同步 `src/compute/client.js`
- **凭证敏感**:`wb-accounts.json` / `wb-sync.json` / `wb-admin.json` / `credits.db` 严禁外传(已 gitignore)
- **采集频率**:批量并发 6,属低频访问;勿大幅提高并发
- **云同步为明文传输**:建议 WebDAV 地址使用 https
